03 / PATTERNS WITH CONTEXT

Observed structure, carefully described.

Petal measurements show a distinct Setosa cluster in these supplied observations, while Versicolor and Virginica overlap. Sepal measurements overlap more strongly. Use the two presets to compare those views; visible separation is not independent classifier validation.

The CSV contains fifty rows per species and four measurements in centimetres. Identical measurement rows are retained because equal values alone do not establish duplicate sampling. The supplied dataset variant and its documented rows 35 and 38 are preserved rather than silently replaced. Filtering changes the view, not the source data.

No model is trained, no biological cause is inferred and no population-wide classification performance is measured. Pooled relationships can reflect differences between species. Original coursework, distributions, summaries and provenance remain available in the source.
