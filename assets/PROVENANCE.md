# Preview provenance

The preview is an authentic application screenshot or a chart from this project, proportionally cropped/padded for repository presentation. Application records are synthetic. The social-preview.png graphic contains that real image and a project label, not a fabricated application interface.

See the project and the central portfolio assets/PROVENANCE.md for source data and generation details.
## V3 descriptive figures

results/relationships.png, distributions.png and profiles.png are generated by explore_iris.py from the unchanged supplied iris.csv. Input hash, historical-variant note, counts and software versions are recorded in results/analysis.json. Colours are observed species labels. Jitter is visual only; bars show sample SD rather than confidence intervals. Source CI tests and exports exact-revision figures with hashes.
